# מכרז 🏀

משחק מכרז שחקנים בזמן אמת. שחקנים מתחרים על חמישייה פותחת
בתקציב מוגבל, עם טיימר לכל תור.

- **client** — React + Vite, ממשק בעברית (RTL)
- **server** — Express + Socket.IO

---

## הרצה מקומית

```bash
npm run setup     # מתקין תלויות בקליינט ובשרת
npm run build     # בונה את client/dist
npm start         # מריץ על http://localhost:3001
```

או בפקודה אחת: `npm run serve`.

> `client/dist` **אינו** נשמר ב-git. חייבים `npm run build` לפני `npm start`,
> אחרת השרת יציג הודעה שמסבירה בדיוק מה להריץ.

### פיתוח

```bash
npm run dev:server   # שרת על 3001
npm run dev:client   # Vite על 5173, עם proxy ל-socket.io
```

## פריסה לענן

השרת מגיש גם את ה-API וגם את הקליינט, אז צריך שירות אחד בלבד.
הפרויקט כולל [`render.yaml`](render.yaml) מוכן ל-Render.

### Render (מומלץ, יש תוכנית חינם)

1. היכנסו ל-[render.com](https://render.com) והתחברו עם GitHub
2. **New → Blueprint**, בחרו את המאגר `nba-auction-game`
3. Render יקרא את `render.yaml` לבד. לחצו **Apply**
4. אחרי כ-3 דקות תקבלו כתובת כמו
   `https://nba-auction-game.onrender.com` — זו הכתובת שמחלקים לחברים

מה ש-Render מריץ:

| שלב | פקודה |
|---|---|
| Build | `npm run build` (מתקין הכל ובונה את הקליינט) |
| Start | `npm start` |
| Health check | `GET /healthz` |

### שני דברים שחשוב לדעת על התוכנית החינמית

**1. השירות נרדם.** אחרי ~15 דקות בלי תנועה Render מכבה אותו,
והכניסה הבאה לוקחת 30-60 שניות עד שהוא מתעורר. אחרי זה הכל מהיר.
שווה להזהיר את מי שמתחבר ראשון.

**2. הדיסק זמני.** `users.json` ו-`leaderboard.json` נמחקים בכל
הפעלה מחדש — כלומר **טבלת האלופים והסיסמאות מתאפסות** מדי פעם.

לפתרון בתוכנית בתשלום: בטלו את ההערה על בלוק ה-`disk` ב-`render.yaml`
והוסיפו `DATA_DIR=/var/data` ל-`envVars`. השרת יזהה את הדיסק לבד.
אם `DATA_DIR` לא ניתן לכתיבה, השרת לא קורס — הוא נופל חזרה
לאחסון זמני ורושם אזהרה בלוג.

### חלופות

Fly.io ו-Koyeb עובדים גם הם ותומכים ב-WebSockets. כל שירות שמריץ
Node ומכבד `PORT` יתאים — אין תלות ב-Render.
